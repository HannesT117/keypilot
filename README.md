# macOS Tools

Small macOS utilities built with AI.

## Tools

| Tool | Description |
|------|-------------|
| [KeyPilot](keypilot/) | Keyboard-driven app switcher — Right ⌘ + letter to jump to any app |
| [BabyKeys](babykeys/) | Lock keyboard and touchpad so that your baby (or anyone else) can't do anything unintended |
